# Glossary

*As of 2026-10-21.* The product's words, and what each means. Use them in every document and item,
and on every screen. Taken from the words on InPoster's screens today; where a screen uses two
words for one thing, the one to use is listed first.

| Term | Means | Not to be confused with |
|---|---|---|
| Post | One piece of LinkedIn content in InPoster: its text, its tone, optionally one picture, and its status | A LinkedIn post: what appears on LinkedIn after publishing |
| Status | Where a post is in its life: Draft, Approved, Published or Discarded | |
| Draft | A saved post not yet approved. Shown in the Drafts column of the Queue and on the Dashboard as "Drafts Pending" | A variant, which is not saved yet |
| Approved | A post the user has accepted and that is ready to publish | Published |
| Published | A post InPoster has sent to the user's Make.com scenario, which accepted it. InPoster does not check that it actually appeared on LinkedIn | Approved |
| Discarded | A draft the user threw away. It is hidden everywhere and cannot be brought back from the screens | Deleted, which removes the post from InPoster for good |
| Delete | Removes a post from InPoster for good, after a confirmation. Deleting a published post does not remove it from LinkedIn | Discard |
| Compose | The page where the user describes a topic and gets variants; also where a draft is edited | |
| Topic | What the user wants to post about; the one required field on Compose ("What do you want to post about?") | Areas of interest |
| Key points, target audience, call to action | Optional details on Compose that guide the AI's writing | |
| Variant | One of the two versions the AI writes for a topic. The user can edit it, add a picture, and "Save as Draft" | Draft |
| Generate, Regenerate | Ask the AI for (new) variants | |
| Tone | The voice of a post: Professional, Conversational, Inspirational or Provocative | |
| Length | Short (about 300 characters), Medium (about 600) or Long (about 1,300). A guide to the AI, not a hard limit | The character counter, which counts against 1,300 |
| Hashtags, emojis | How many hashtags (0 to 10) and whether to use emojis in generated posts | |
| Preferences | The default tone, length, hashtag count and emoji choice that Compose starts with | |
| Inspire Me | Asks the AI for five fresh post ideas, plus one or two follow-ups when the user has published before | |
| Fresh idea | A suggested topic based on the user's areas of interest | Follow-up |
| Follow-up ("Continue a Thread") | A suggested topic that continues one of the user's recent published posts | Fresh idea |
| Areas of interest | Up to ten subjects the user cares about, set in Settings, that shape Inspire Me | Topic |
| Picture (image) | The one image a post may carry: uploaded, generated by AI, or chosen from Unsplash | |
| Upload | Attach a picture from the user's computer: JPEG, PNG, GIF or WebP, up to 5 MB | |
| Generate Image | Make a picture with OpenAI's DALL-E 3 from an image prompt | |
| Image prompt | The description DALL-E 3 draws from. "Suggest" asks Claude to write one from the post's text | Topic |
| Search Unsplash | Find a free stock photo on Unsplash and attach it | |
| Queue (Review Queue) | The page with three columns, Drafts, Approved and Published, where posts are approved and published | Timeline |
| Publish Now | Sends an approved post to the user's Make.com scenario after a confirmation | Resend |
| Resend | Sends an already published post to Make.com again | Publish Now |
| Timeline | The page listing published posts, newest first, grouped by month | Queue |
| Dashboard | The home page: totals, drafts pending, posts published this week, recent drafts | |
| Make.com scenario | The automation the user builds in their own Make.com account that receives a post from InPoster and posts it to LinkedIn | |
| Make.com address | The web address Make.com gives the user's scenario; pasted into Settings so InPoster knows where to send posts. It is the first field of the Make.com section in Settings, labelled with Make.com's own technical name for it | |
| Access key | A secret a service (Anthropic, OpenAI, Unsplash, optionally Make.com) gives the user so InPoster can use it on their behalf. Stored scrambled, shown only as dots | A password to InPoster: there is none |
| Model | Which Claude writes the posts: Sonnet 4.6 (recommended) or Haiku 4.5 (faster and cheaper) | |
| Theme | Dark (the default) or Light appearance | |
