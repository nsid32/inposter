## Non-goals

*(Inferred from the project's own notes and the earlier feature history.)*

- **A hosted version, sign-in or several users.** InPoster is a personal tool that runs on one
  computer; the project's contribution guide says features that need a hosted service are out of
  scope.
- **Connecting to LinkedIn directly.** It was built and removed: LinkedIn restricts the access it
  needs to a separate approved app, which was too much setup for a personal tool. Publishing goes
  through Make.com only.
- **Bringing existing LinkedIn posts or their likes and comments into InPoster.** Removed with the
  direct connection, for the same reason.
- **Marketing pages or a public website for InPoster itself.**
